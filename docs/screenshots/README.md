# Screenshots

This directory is a placeholder for real screenshots of the running stack.

Once you have run `docker compose up -d` locally, add screenshots here, e.g.:

- `grafana-dashboard.png` - the "Service Health" Grafana dashboard
  (request rate, error rate, latency, target up/down panels)
- `prometheus-targets.png` - the Prometheus Targets page showing all
  scrape targets as `UP`
- `alertmanager-alerts.png` - the Alertmanager UI showing a firing/routed
  alert

No screenshots are checked in yet - this README and `.gitkeep` exist so the
directory is tracked by git and the README's "Screenshots" section has a
real place to point to.
